# Shelf photos

- `inbox/` — drop new shelf photographs here (straight on, one shelf per frame,
  spines filling the picture). From a phone, use the site's "Add to the
  library" section or GitHub's upload page for this folder.
- `shelves/` — processed photos, archived by the `/add-books` skill after the
  books they show have entered the catalog.

The original five photographs that seeded the catalog (July 2026) were
processed directly from the chat session and are not stored here.
